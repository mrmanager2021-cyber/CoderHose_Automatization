# CoderHouse Automatización – Checkpoint 1

Descripción
Es un agente de cartera que entrega informacion a de los clientes que estan debiendo a la empresa se puede buesacar un ejemplo con este google sheets,
https://docs.google.com/spreadsheets/d/1j7ZwgaICCo3jWqZPpFFu5xVTDbWFpszNvsBDXbGVB4U/edit?usp=sharing

el agente busca por cliente y por ciudad en el system prompt esta configurado la manera de responder, las reglas y demas datos que pedia la entrega
son 202 filas de busqueda de A:N colomnas de informacion, el agente entrega colomnas de informacion requeridas en el systemp promt de acuerdo al uso de busqueda si es por cliente o por ciudad.
